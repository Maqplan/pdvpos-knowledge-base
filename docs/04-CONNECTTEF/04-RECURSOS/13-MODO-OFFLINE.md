# Modo offline

O guia atual da API Smart POS não especifica um modo offline para iniciar ou concluir pagamentos. Falhas e reenvios devem seguir a orientação publicada pela ConnectTEF; não inferir operação offline a partir disso.

[Falhas e reenvio](https://connecttef.com.br/docs/smartpos-erp-web-api/webhooks/retry) · [Documentação oficial](https://connecttef.com.br/docs)
